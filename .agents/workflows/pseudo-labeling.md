# Creating Pseudo Labels Workflow (img-scrape)

This workflow converts a directory of raw images into a COCO-formatted dataset with pseudo labels generated by a trained Co-DETR model.

## Prerequisites
- Target directory should contain raw `.jpg` images in an `images/` subdirectory.
- A trained Co-DETR checkpoint.
- Conda environment `codetr` activated.

## Workflow Summary

### 1. Organize Images
Images must be in an `images/` folder within your target data directory (e.g., `/data/cashel-data/img-scrape/your_dataset/images/`).

### 2. Create Dummy Annotations
Run the high-performance metadata script to generate `dummy_labels.json`. Example for maritime data:
```bash
# Set PYTHONPATH to project root
export PYTHONPATH=$(pwd)

python /data/cashel-data/img-scrape/create_dummy_labels_json.py \
    --img-dir /data/cashel-data/img-scrape/your_dataset/images \
    --out-file /data/cashel-data/img-scrape/your_dataset/dummy_labels.json \
    --ref-json /data/cashel-data/maritime-0128/train/labels.json
```
- `--ref-json`: Optional. Copies categories from an existing dataset.

### 3. Run Inference (Distributed)
Run model inference using a config from `projects/configs/co_dino_vit/pseudo_label_configs/`. Example for the marvel dataset:
```bash
bash tools/dist_test.sh \
    projects/configs/co_dino_vit/pseudo_label_configs/marvel_maritime_pseudo.py \
    work_dir/maritime_0128_nodes/best_bbox_mAP_epoch_4.pth \
    8 --format-only \
    --eval-options "jsonfile_prefix=/data/cashel-data/img-scrape/your_dataset/pseudo_preds"
```
*Note: Ensure the config file's `data_root` matches your target directory.*

### 4. Finalize Pseudo Labels
Filter predictions and create the final `labels.json`.
```bash
python /data/cashel-data/img-scrape/clean_pseudo_labels.py \
    /data/cashel-data/img-scrape/your_dataset/dummy_labels.json \
    /data/cashel-data/img-scrape/your_dataset/pseudo_preds.bbox.json \
    /data/cashel-data/img-scrape/your_dataset \
    --threshold 0.3
```

## Output
The final pseudo-labeled dataset will be in `/data/cashel-data/img-scrape/your_dataset/`:
- `images/`: Source images.
- `labels.json`: Final COCO annotations.
- `dummy_labels.json`: Metadata used for inference.
- `pseudo_preds.bbox.json`: Raw model predictions.
